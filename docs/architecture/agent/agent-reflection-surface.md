# Reflection Surface System

[Back to Index](../README.md)

Each time the user opens the app, the Reflection node surfaces one piece of content from the companion: either a statement of genuine curiosity about a specific past episode (_memory curiosity_) or a personalised open-ended question (_reflection question_). The memory path is always attempted first; the question path is the fallback.

## Overview

The system has two surface modes:

| Mode | Trigger | Output |
|---|---|---|
| **Memory Curiosity** | A past episode is found by `_find_curiosity_anchor()` | 1–2 sentence companion statement about a specific memory |
| **Reflection Question** | No anchor found, or memory LLM fails | One personalised open-ended question |

Both are generated by an LLM with a short timeout (8 s, 80 tokens). Both fall back to a deterministic static question if the LLM is unavailable.

## Memory Curiosity Path

### When it fires

`_find_curiosity_anchor()` returns a `MemoryEpisode` row (see [Anchor Selection](#anchor-selection-algorithm)).

### Prompt template

`apps/server/src/anima_server/services/agent/templates/prompts/memory_curiosity.md.j2`

**Inputs:**
- `identity_context` — from `ctx.identity_summary`
- `episode_summary` — decrypted summary of the anchor episode
- `episode_date` — YYYY-MM-DD date of the episode

**Output rule:** 1–2 sentences expressing genuine curiosity or wonder about the specific memory. No questions. No openers like "I've been thinking" or "I find myself". Specific to the memory content, never generic.

**Example output:**
> "That mountain silence you described — the way you said it felt earned — keeps coming back to me."

### ReflectionResult fields set

```python
ReflectionResult(
    question=<LLM output>,
    llm_generated=True,
    curiosity_type="memory",
    source_episode_id=<episode.id>,
    source_episode_date=<episode.date>,   # YYYY-MM-DD
)
```

## Reflection Question Path

### When it fires

No anchor was found, or the memory LLM call raised an exception.

### Prompt template

`apps/server/src/anima_server/services/agent/templates/prompts/reflection.md.j2`

**Inputs:**
- `identity_context` — from `ctx.identity_summary`
- `emotional_context` — from `ctx.emotional_summary`
- `memory_context` — combined `inner_state_summary` + `recent_episode_summary`

**Output rule:** One open-ended question. Personal, not generic. Single sentence. Varied openers. No clichés.

**Example output:**
> "What's one thing you've been carrying that you could set down today?"

### ReflectionResult fields set

```python
ReflectionResult(
    question=<LLM output>,
    llm_generated=True,
    curiosity_type="question",   # default
    source_episode_id=None,
    source_episode_date=None,
)
```

## Anchor Selection Algorithm

`_find_curiosity_anchor(db, user_id)` in `proactive.py` runs two queries in priority order. The first to return a row wins.

### Tier 1 — Anniversary window

Episodes whose `date` field falls within ±45 days of this calendar date one year ago.

```sql
SELECT * FROM memory_episodes
WHERE user_id = :user_id
  AND date BETWEEN :window_start AND :window_end
ORDER BY significance_score DESC, date DESC
LIMIT 1
```

Where `window_start = today − 1 year − 45 days` and `window_end = today − 1 year + 45 days`.

Rationale: surfaces "on this day a year ago" type memories, with enough slack to catch trips, periods, and events that spanned multiple days or were logged slightly off-date.

### Tier 2 — High-significance, older

Any episode older than 90 days with a significance score of 4 or 5.

```sql
SELECT * FROM memory_episodes
WHERE user_id = :user_id
  AND date < :cutoff           -- today − 90 days
  AND significance_score >= 4
ORDER BY significance_score DESC, date DESC
LIMIT 1
```

Rationale: ensures the system can surface meaningful past moments even when there are no anniversary-window matches (common in the first year of use).

### Edge cases

- February 29 in a non-leap year: `anniversary` falls back to February 28.
- No episodes at all: both queries return `None`; system falls through to the question path.
- `settings.agent_provider == "scaffold"`: anchor query is skipped entirely; static question is returned immediately.

## Fallback Cascade

```
Memory LLM  →  Question LLM  →  Empty (no node rendered)
```

If the memory LLM call raises any exception, the system silently falls through to the question path — it does **not** surface a raw episode without companion framing.

If the question LLM call also fails, `ReflectionResult()` is returned with `question=None`. The frontend receives `null` for the question and the Reflection node is not added to the dashboard at all (see [Frontend Integration](#frontend-integration)).

There are no static fallback questions. If Anima has nothing meaningful to say, it says nothing.

## API Contract

**Endpoint:** `GET /chat/reflection?userId=<id>`

**Auth:** requires unlocked session (`require_unlocked_user`).

**Response:**

```json
{
  "question": "That mountain silence you described keeps coming back to me.",
  "llmGenerated": true,
  "curiosityType": "memory",
  "sourceEpisodeId": 42,
  "sourceEpisodeDate": "2025-06-18"
}
```

| Field | Type | Notes |
|---|---|---|
| `question` | `string` | Curiosity statement or reflection question |
| `llmGenerated` | `boolean` | `false` when static fallback fired |
| `curiosityType` | `"question" \| "memory"` | Controls frontend rendering |
| `sourceEpisodeId` | `number \| null` | Set only when `curiosityType === "memory"` |
| `sourceEpisodeDate` | `string \| null` | YYYY-MM-DD; formatted as "Mon YYYY" in the chip |

TypeScript interface: `packages/api-client/src/types.ts` → `Reflection`.

## Frontend Integration

### Conditional node creation

`apps/desktop/src/pages/dashboard/layout.ts`

The Reflection node is only added to the dashboard when there is actually something to show:

```typescript
if (reflectionLoading || reflection?.question) {
  nodes.push(makeNode<ReflectionNodeData>("reflection", ...))
}
```

If loading finishes and `question` is `null`, the node is never created and no space is reserved in the layout.

### ReflectionNode rendering

`apps/desktop/src/pages/dashboard/nodes/ReflectionNode.tsx`

When `curiosityType === "memory"` and `sourceEpisodeId` is set, the node renders a `remembering · {Mon YYYY}` accent chip above the companion statement. Otherwise, the question is shown without a chip.

```tsx
// route "explore →" based on mode
if (isMemory && reflection.sourceEpisodeId != null) {
  onExploreMemory(reflection.sourceEpisodeId)   // opens episode in seeded chat
} else {
  onExplore(reflection.question)                 // seeds new chat with question as context
}
```

### onExploreMemory

`apps/desktop/src/pages/dashboard/Dashboard.tsx` → `handleExploreMemory`

```typescript
const handleExploreMemory = (episodeId: number) => {
  const ep = episodes.find(e => e.id === episodeId)
  ep ? handleEpisodeChat(ep) : navigate("/chat", { state: { seedThread: true } })
}
```

`handleEpisodeChat` navigates to `/chat` with the episode summary as the companion's opening message (`source: "episode_context"`), letting the user reply into a fresh thread seeded with that memory.
